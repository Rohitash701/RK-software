# RK SOFTWARE — refreshed website files

This package updates the visual front end with a black, orange and white theme, responsive navigation, service sections, tool cards, INR/USD display toggle and ₹0/$0 starter prices.

## Upload to GitHub
1. Open your repository: https://github.com/Rohitash701/RK-software
2. Upload/replace `index.html`, `styles.css`, `app.js`, and `README.md` in the repository root.
3. Keep the exact filename `styles.css` (plural).
4. Commit the changes.
5. If GitHub Pages is already enabled, refresh the published website after the deployment completes.

## Important
This is a front-end design package. Login/register, secure admin, real order storage, payments, tool credits and provider/API fulfilment are NOT live yet. The product cards are catalogue placeholders and the currency selector changes the displayed zero-price symbol only; it does not perform exchange-rate conversion. A production admin panel requires a secure backend, authentication, database and server-side permissions. Never publish API secrets in this repository.
